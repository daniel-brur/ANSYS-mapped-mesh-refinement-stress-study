# Geometry and Model Notes

The input file defines a 2D outline with 16 keypoints and constructs four areas from line selections. It uses a mapped-mesh workflow for areas 2, 3, and 4.

The physical units of the geometry are not specified in the supplied source and must be established by the analyst.

Before changing keypoints or line order, check the `FLST`/`FITEM` selections, area definitions, `LESIZE` assignments, `AMAP` keypoint order, boundary conditions, and pressure line numbers.
